# ID — Short concrete title

| Field | Value |
| --- | --- |
| Type / priority / status | Bug or feature / P0–P3 / proposed |
| Owner | Unassigned or explicit owner |
| GitHub | Link, or none (internal record) |
| Spec | Relative link |
| Sources | Relative links to dated source notes |
| Dependencies | IDs and reason; none if independent |

## Problem and scope

Describe the observed behavior or requested outcome. Separate confirmed evidence from hypotheses. State what belongs to this repository and any downstream dependency.

## Acceptance

- [ ] Observable result and meaningful verification.
- [ ] Relevant failure, ownership, resource and compatibility cases.
- [ ] Documentation and rollout/rollback evidence.

## Evidence and status history

Date, commit/PR, validation actually performed and remaining limitations. Link sanitized artifacts; never attach secrets or private media. Spec publication alone is not implementation completion. Add the item to the backlog index and append a wiki log entry.
